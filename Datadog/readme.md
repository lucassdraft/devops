# Monitoramento e observabilidade

**Monitoramento** é o processo de coletar dados para entender o que está acontecendo dentro da sua infraestrutura.
**Observabilidade** é usar os mesmos dados que você coletou e ir além do "o que esta acontecendo?" para endender "por que está acontecendo?"
